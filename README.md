# واژه‌به‌واژه — نسخهٔ اصلاح‌شده

این نسخه بر اساس مخزن https://github.com/nellavitrina-cloud/leitner-fa و commit زیر تهیه شده است:
`fe15c3c35fc4779ef2841705675cf86104997dbb`
فهرست واژه‌ها بر اساس فایل ارائه‌شدهٔ leitner-fa.html تکمیل شده است: ۸۵۰ کارت و ۳۱۲۴ مثال ترجمه‌شده.

## علت خرابی
- فایل اصلی فقط ظاهر برنامه را داشت؛ هیچ منطق مرور، اتصال دکمه‌ها یا ذخیره‌سازی وجود نداشت.
- فایل index.html وجود نداشت، درحالی‌که manifest و service worker به آن اشاره داشتند. بنابراین مسیر اصلی ورودی نداشت و پیش‌ذخیره‌سازی آفلاین شکست می‌خورد.
- آیکون icon.png موجود نبود.
- فهرست اولیه فقط کارت come داشت؛ اکنون هر ۸۵۰ کارت فایل منبع با معنی، نقش واژه، یادداشت و مثال‌ها در cards.js موجود است.

## راه‌اندازی روی رایانه
1. فایل ZIP را از حالت فشرده خارج کنید.
2. Node.js نسخهٔ ۱۸ یا بالاتر روی رایانه لازم است.
3. در پوشهٔ فایل‌ها، ترمینال را باز کنید و اجرا کنید:

```sh
node server.js
```

4. آدرس http://127.0.0.1:8080 را باز کنید. برای توقف، Ctrl+C بزنید.
نیازی به npm install یا ساخت پروژه نیست. برای آزمایش PWA فایل HTML را با دوبارکلیک باز نکنید؛ از آدرس بالا استفاده کنید.

## انتشار دلخواه روی Vercel یا میزبان فایل ثابت
فایل‌های این پوشه را جایگزین فایل‌های پروژه کنید. Framework Preset را Other انتخاب کنید؛ فرمان نصب و ساخت نیاز نیست و پوشهٔ خروجی همان ریشهٔ فایل‌ها است. index.html باید در ریشهٔ سایت باشد. فایل server.js فقط برای اجرای محلی است.
این راهنما انتشار خودکار انجام نمی‌دهد. نصب و آفلاین به HTTPS یا localhost نیاز دارند. پس از انتشار نسخهٔ جدید همهٔ پنجره‌های برنامه را ببندید و دوباره باز کنید تا service worker جدید فعال شود. برای انتشارهای بعدی نام CACHE_NAME در sw.js را تغییر دهید.

## رفتار مرور
کارت جدید در جعبهٔ اول است. پاسخ درست یک جعبه جلو می‌رود (حداکثر ۵)، پاسخ غلط به جعبهٔ اول برمی‌گردد. فاصله‌های جعبه‌ها ۱، ۲، ۴، ۸ و ۱۶ روز است؛ بنابراین اولین پاسخ درست مرور بعدی را برای دو روز بعد ثبت می‌کند. تمرین آزاد و تمرین کارت‌های ضعیف نیز پیشرفت را تغییر می‌دهند. هر کارت در هر نوبت یک بار ارائه می‌شود. «نوبت تازه» امکان تمرین مجدد را می‌دهد.

پیشرفت در localStorage همان مرورگر و همان آدرس ذخیره می‌شود. از بخش آمار فایل پشتیبان بگیرید. بازیابی و شروع دوباره تأیید می‌خواهند. پشتیبان ناسازگار یا خراب پذیرفته نمی‌شود؛ دادهٔ خراب قبلی نیز خودکار بازنویسی نمی‌شود. هم‌زمان فقط در یک پنجره مرور کنید؛ ادغام پیشرفت چند پنجره پیاده‌سازی نشده است.

آفلاین پس از اولین بارگذاری موفق و آماده‌شدن service worker کار می‌کند. تلفظ وابسته به امکانات مرورگر و صدای نصب‌شده است و آفلاین تضمین نمی‌شود. نمایش دکمهٔ نصب نیز به مرورگر بستگی دارد.

## افزودن واژه‌های اصلی
فهرست اصلی را در cards.js اضافه کنید. هر کارت باید id یکتا و ثابت، word، fa، type، category و examples داشته باشد. category یکی از verb، noun، adj یا other است. examples آرایه‌ای از اشیای tense، en، fa است؛ note اختیاری است. شناسهٔ کارت‌های موجود را تغییر ندهید تا پیشرفت معتبر بماند. تعداد واژه‌ها خودکار محاسبه می‌شود. شناسهٔ come حفظ شده است تا پیشرفت قبلی با فهرست کامل سازگار بماند.
